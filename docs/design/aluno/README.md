## Regras que estas telas materializam

- **Nada de outro aluno.** Sem ranking nominal; a comparação é só contra a média
  da turma, de forma anônima e configurável pela instituição.
- **Só o que foi publicado.** Nota em rascunho do professor não aparece aqui.
- **Média explicável.** "Como sua média foi calculada" mostra cada avaliação, seu
  peso e a conta — é requisito, não enfeite.
- **O celular é o dispositivo primário.** A barra inferior substitui a sidebar;
  alvos de toque de 44px para cima.
